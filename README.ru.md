# Ghost

Голосовой помощник для Linux: слышит вопрос, при необходимости смотрит на экран и печатает ответ в компактном оверлее.

**[English version →](README.md)**

![Оверлей Ghost с демонстрационными вопросом и ответом](assets/readme/overlay-answer.png)

_Это настоящий рендер `QWidget` с безопасным демонстрационным текстом. Микрофон, живая модель и личные данные не использовались._

**Стек:** Python 3 · PySide6 / Qt 6 · faster-whisper или Groq STT · адаптеры Claude Code, Codex и других CLI

## Что умеет

- Записывает голосовой вопрос и определяет, когда речь закончилась.
- Распознаёт речь локально через `faster-whisper` или через Groq, если он настроен.
- При необходимости добавляет к вопросу временный снимок экрана.
- Печатает ответ по частям в Qt-оверлее поверх других окон.
- Даёт выбрать инструмент и модель из редактируемого реестра [`tools.yaml`](src/tools.yaml).
- Отменяет работу без зависания интерфейса и не перезапускается, пока ресурсы не освобождены.

## Как это работает

```text
микрофон → VAD → процесс STT ──────┐
                                   ├→ CLI-адаптер модели → сигналы Qt → оверлей
необязательный снимок экрана ──────┘
```

Интерфейс остаётся в главном потоке Qt. Запись звука, распознавание, обмен с моделью,
отмена и очистка ресурсов отделены потоками и процессами. Подробные контракты описаны в
[`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).

## Запуск

Сейчас Ghost рассчитан на Linux. Установите и авторизуйте хотя бы один поддерживаемый
CLI для работы с моделью, затем выполните:

```bash
git clone https://github.com/Archangel-gabri/ghost-assistant.git
cd ghost-assistant
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
./run.sh
```

Режим распознавания `auto` использует Groq, если задан `GROQ_API_KEY`, иначе переключается
на локальный `faster-whisper`. Другой совместимый CLI можно добавить в
[`src/tools.yaml`](src/tools.yaml). Команда `./install.sh` дополнительно создаёт пункт в меню
приложений и ярлык на рабочем столе.

## Ограничения

- Модель не входит в поставку. Для ответов нужен настроенный Claude Code, Codex или совместимый CLI.
- Работа звука, локальной модели распознавания и внешнего провайдера зависит от окружения компьютера.
- Захват экрана необязателен; его лучше отключить, если на экране могут быть чувствительные данные.
- Офлайн-тесты проверяют локальные процессы и очередь событий Qt, но не доказывают качество микрофона,
  доступ к живому провайдеру и работу захвата на любом рабочем столе.

Датированные результаты тестов, закреплённые версии и протокол нативных проверок вынесены в
[`docs/STATUS.md`](docs/STATUS.md). Команды для разработчиков находятся в
[`CONTRIBUTING.md`](CONTRIBUTING.md).
